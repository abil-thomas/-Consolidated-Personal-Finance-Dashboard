Data quality notes

Keep the numbers honest.
An expense-only export is not proof of complete spending, income, account balances or net worth.
  • Bank statements and credit-card purchases may overlap. Reconcile before treating totals as complete.
  • Transfers between your own accounts are not spending.
  • Market prices and brokerage data are not automatically fetched in this starter version.

Import & backup

Bring data in, take it with you, keep a safe copy.

Import transactions / backup

Choose a JSON file from this app or from the Python Excel importer. Existing records are preserved; exact matching fingerprints are skipped.

Export a full backup

Export transactions and holdings to a portable JSON file, then transfer it privately to another device.

Backups are not encrypted by this starter app. Store them somewhere private.

Import your Money Manager data

The prepared transaction file is kept separate from the public app for privacy.

Download the private JSON file separately, then choose it using the JSON file picker above. Never upload it to GitHub.

Local data & reset

Data is stored in this browser's IndexedDB. Clearing browser data can erase it. Export backups regularly.

Import merges; it does not delete existing records. Two genuinely separate but identical transactions may be treated as duplicates.

Move data between devices

No account or cloud database required.
  1. Export a JSON backup on device A.
  2. Transfer the file privately (AirDrop, iCloud Drive or another private method).
  3. Import it on device B. Matching fingerprints are skipped.
  4. Keep dated backups to recover from accidental edits or device loss.
